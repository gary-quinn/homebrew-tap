# Homebrew tap

Tap for Gyra (Wave 1 early access).

```bash
brew tap gary-quinn/tap
brew install --cask gyra
```

On Homebrew 6+, you may need to trust the cask once:

```bash
brew trust gary-quinn/tap/gyra
```

Artifacts ship from [gary-quinn/gyra-releases](https://github.com/gary-quinn/gyra-releases).

Source: [gary-quinn/gyra](https://github.com/gary-quinn/gyra) (private).
